# Reporting Security Issues

Agent traces can contain source code, credentials, prompts, and personal information. Do not put a sensitive trace or token in a public issue. Report reproducible security defects through the repository's private vulnerability reporting channel when available, or contact a maintainer privately through the repository host.

Include the affected release, platform, a synthetic reproducer, and the security impact. The localhost server uses a per-process token. Captures are data, and their embedded text must never be executed as instructions. Redaction reduces common disclosure risks but does not establish that arbitrary text is anonymous.

The project currently offers no response-time guarantee. Before a public release, maintainers must enable a private reporting channel and document supported versions.
